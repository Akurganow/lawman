# Lawman

An executive branch for software repositories: patrols that file reports, an investigation that builds the case, a prosecutor that decides whether to charge, a court that rules, and clerks that carry a verdict to a pull request. It runs inside the agent harness a developer already uses, on that harness's own schedule, with the `git` and `gh` already on the machine.

Status: design. Nothing here runs yet.
