## Entry block

Copy this block into the entry of the precinct word for word. The assembly fills only the tool name and version and the project address in the User-Agent line.

- Source: deps-dev. Level: version. A finding rests on it: yes.
- Pin carries: name, version.
- Request: POST https://api.deps.dev/v3alpha/versionbatch
- Headers: `Content-Type: application/json`
- Values: the body is `{"requests":[{"versionKey":{"system":"{system}","name":"{name}","version":"{version}"}}, ...]}`. `{system}` is `NPM` for npm, `PYPI` for PyPI, `CARGO` for crates.io, `GO` for Go, `MAVEN` for Maven, `NUGET` for NuGet and `RUBYGEMS` for RubyGems. `{name}` passes the class `<name>` of a `licenses` line. Maven writes `group:artifact`. Go writes the module path. `{version}` passes the class `<pin>`. For Go the role adds `v` when the pin has none.
- Key of the reply: the echo `responses[i].request.versionKey` with its system, name and version. The role matches a pin by the echo and not by its place. When the number of responses differs from the number of requests, or `nextPageToken` is not empty, every pin of the reply is `unread`.
- Take: the list of strings `responses[i].version.licenses`. When the object `version` is missing, the answer is `no-record`.
- Reply form: JSON batch
- Batch: up to 100 pins per request.
- Pace: none stated by the service. The interval is the time of the request at the live read of the assembly.
- Requests per pin: not counted for a batch row. One request carries up to 100 pins, and one batch is 1 request.
- User-Agent: <tool name and version>; <project address>
- Attribution: Open Source Insights (deps.dev), CC-BY-4.0
